Projet Labyrinthe

Ce projet a pour objectif de générer, afficher et résoudre automatiquement un labyrinthe à l’aide d’algorithmes de graphes et de génération procédurale.
Il a été réalisé en Python dans le cadre d’un projet universitaire d’algorithmique.

Fonctionnalités principales

Génération du labyrinthe à partir d’une grille grâce à l’algorithme de Prim (algo_Prim.py, generation_grille.py)

Représentation du graphe et gestion des arêtes / sommets (graphe.py)

Affichage graphique du labyrinthe (render.py)

Résolution automatique du labyrinthe (resolution.py)

Exécution complète du projet via main.py

Fichiers de test pour valider le bon fonctionnement (test.py)
